### 01 · [AMLSentinel — Intelligent AML Investigation Platform](https://github.com/Nafiasulthana/AMLproject)

![Python](https://img.shields.io/badge/Python-211137?style=flat-square&logo=python&logoColor=white) ![FastAPI](https://img.shields.io/badge/FastAPI-6D28D9?style=flat-square&logo=fastapi&logoColor=white) ![React](https://img.shields.io/badge/React-211137?style=flat-square&logo=react&logoColor=white) ![Neo4j](https://img.shields.io/badge/Neo4j-6D28D9?style=flat-square&logo=neo4j&logoColor=white) ![XGBoost](https://img.shields.io/badge/XGBoost-211137?style=flat-square)

An investigation platform that brings together transaction data, relationship graphs and machine learning to surface potentially suspicious financial activity.

- Built a risk-scoring approach combining rules, behavioral signals, graph metrics and XGBoost.
- Developed FastAPI endpoints for transaction analysis and investigator workflows.
- Used PostgreSQL for structured records and Neo4j to explore fund-flow relationships.
- Added SHAP explanations, case management, interactive flow visualizations and suspicious transaction report (STR) PDF generation.
- Built a multithreaded synthetic transaction simulator to exercise detection scenarios.

**[Explore AMLSentinel →](https://github.com/Nafiasulthana/AMLproject)**

### 02 · [TalentAI — RAG-Based Resume Analysis](https://github.com/Nafiasulthana/chatbot)

![Streamlit](https://img.shields.io/badge/Streamlit-211137?style=flat-square&logo=streamlit&logoColor=white) ![LangChain](https://img.shields.io/badge/LangChain-6D28D9?style=flat-square) ![FAISS](https://img.shields.io/badge/FAISS-211137?style=flat-square) ![Hugging Face](https://img.shields.io/badge/Hugging_Face-6D28D9?style=flat-square&logo=huggingface&logoColor=white)

A local-first assistant that reads PDF resumes and helps answer recruiter questions from retrieved candidate information.

- Designed the PDF extraction, chunking and semantic search pipeline.
- Combined FAISS retrieval with a LangChain-powered RAG workflow.
- Used Qwen2.5-1.5B-Instruct for profiling, job-fit insights and grounded Q&A.
- Produced structured candidate profiles and JSON-formatted portfolio content without requiring an external LLM API key.

**[Explore TalentAI →](https://github.com/Nafiasulthana/chatbot)**

### 03 · Customer Churn Prediction & Retention

![Scikit-learn](https://img.shields.io/badge/Scikit--learn-211137?style=flat-square&logo=scikitlearn&logoColor=white) ![XGBoost](https://img.shields.io/badge/XGBoost-6D28D9?style=flat-square) ![SHAP](https://img.shields.io/badge/SHAP-211137?style=flat-square)

A machine learning study focused on spotting customers likely to leave and interpreting which factors drive churn.

- Compared XGBoost and Random Forest models using five-fold cross-validation and GridSearchCV.
- Addressed class imbalance with SMOTEENN and interpreted predictions with SHAP.
- **Reported XGBoost results:** 87.4% accuracy · 85.8% F1-score · 0.91 ROC-AUC.
- Related research work includes sales forecasting and dynamic pricing.
